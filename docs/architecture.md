# v0.1 架构与后续开发

## 执行链

用户提问 → 创建持久化任务 → 主 Agent 接收 Skill 摘要目录 → 模型选择 `load_skill` → 根据方法调用搜索/采集/本地资料工具 → 返回有来源的结果 → 继续调查或 `finish_research`。

代码执行工具，模型只提出调用。后端校验参数、访问限制和任务预算；所有关键发现要求引用本次已关联的证据 ID。用户内容以文本呈现，不作为 HTML 或代码执行。

## 状态与恢复

任务状态为 queued/running/completed/failed/interrupted/cancelled/limited。最多两个任务同时运行，包含等待任务在内最多六个。事件、来源、工具次数、Token 用量与完整模型对话轮次保存在 SQLite。

恢复从完整轮次继续。部分完成的工具轮次会被丢弃并重新规划；已花费的搜索/页面预算保留，所以恢复不会自动突破预算。记忆建议通过稳定 ID 防止重复生成。只读工具可能重试，网页通过缓存减少重复请求。

取消能停止后续模型调用和调度。已开始的同步网页读取可能在后台完成一个有超时限制的请求，不能保证远端立即停止。

总时限只计算任务获得执行槽位后的时间；单次供应商请求有超时及一次暂时性错误重试。累计 100,000 Token 后停止继续开启新轮次，这不是精确的货币预算，也不能撤回已经发生的费用。

## 证据边界

数据来源区分 `web/full_text`、`search/snippet` 、`import/user_import` 和 `browser/visible_text`（浏览器搜索结果仍为 `snippet`）。检索摘要不能自动提升为正文证据。保存原文链接、采集时间、可获得的发表时间；生效日期由模型结合原文分析，不用抓取时间替代。

网页提取保留正文和最多 40 个相关链接供后续调查。单次返回模型约 6,500 字符，可用 `read_evidence` 分段读取后续内容。PDF 用页标记保留基本定位。

资料按 URL 缓存，每次重新采集产生独立的证据快照，避免后来更新的网页覆盖旧报告依据。尚未实现跨平台同一作者/同一案例的确定性去重，也没有自动建立校友实体库。相关 Skill 要求说明重复样本与身份不确定性。

## 下一阶段优先级

1. 用户提供目标项目与 csapp 网址后，构建约 10–15 个真实问题的评估集；用实际模型和搜索账号验证报告质量、耗时与成本。
2. 根据授权情况接入高价值社媒来源；分别衡量搜索、正文、图片、评论覆盖，避免将首页成功当作完整接入。
3. 增加录取案例/校友路径的结构化字段与人工匹配审核，记录样本分母、未知值、证据时间和身份冲突。
4. 增加政策变化监测与定时任务；订阅更新和实时问答共享证据存储，但由程序负责调度。
5. 只有在评估表明上下文隔离或并行调查确有收益时，再加入多个研究 Agent。

## 浏览器采集通道

`social.py` 使用 Playwright 持久上下文，每平台独立登录目录、异步锁和页面。`search_social` 与 `read_url` 共享研究任务的搜索/页面预算，同时受平台每日限额与请求间隔约束。浏览器操作不接收模型提供的脚本；只执行服务端维护的只读 DOM 提取器。

状态包括 disconnected、awaiting_login、needs_login、restorable、ready、challenge、connection_error。会话 Cookie 仅用于本机登录状态判断，不进入工具结果或模型上下文；ready 表示最近一次检查发现会话，真实权限在每次读取时判断。验证码/限流后需人工恢复，重新启用开关不能清除挑战状态。

HTTP 通用抓取仍使用 robots 和 DNS 固定连接。平台浏览器通道由用户连接后使用，限制平台 HTTPS 顶层导航、阻止本机地址，不继承 HTTP robots 许可判断，也不把用户登录当作平台对自动化的授权。会话操作 API 使用同源写入保护，Agent 不能调用登录、设置或清除会话接口。

登录态复用：独立浏览器目录之外，同目录 `session.json` 以 0600 权限保存平台 Cookie（包含会话 Cookie）。仅补充浏览器缺失且未过期的 Cookie，不延长有效期。第一次登录后点击检查状态或成功采集即可保存；关闭连接保留、清除登录态一并删除。登录态是本机敏感明文文件，不进入 Git、模型或 JSON 导出。平台可随时使会话失效，不能保证永久免登录。

## 研究预算与收尾

未配置的通用搜索、未连接/暂停的社媒以及用尽预算的工具不提供给模型；不可用配置的预检失败不扣搜索预算，已发出的失败搜索请求仍计数。达到配置累计 Token 预算的 80%、页面上限或最后两轮触发收尾，使用原问题与档案上下文、来源 ID 和每份资料前 1400 字的精简上下文，暂停新增搜索。配置的累计 Token 预算（默认 300000，可设 10000–1000000）是常规研究的停止阈值，会在单轮完成后检查，故可能超出。

模型报告 JSON 损坏或引用不合法时明确反馈，无法完成则展示无分析结论的进度摘要，不生成虚构发现。已达上限的任务支持「仅整理已有证据」，明确追加最多两轮模型调用、最多 120 秒，不重置搜索/页面计数。

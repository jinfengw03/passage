# 渡 · Passage 使用指南

[返回项目首页](../README.md)

## 第一次使用

1. 在「个人档案」填写背景、申请季、目标项目和偏好。缺项可以留空。
2. 在「设置」填写模型服务地址、模型名称、API Key，保存并测试连接。支持 **Chat Completions 兼容接口且具有工具调用能力的模型**；DeepSeek 的服务地址可填 `https://api.deepseek.com`，模型 ID 以你的服务商账户为准。本机兼容服务可填 `http://127.0.0.1:端口/v1`。
3. 如需通用联网搜索，配置 Tavily Search Key。模型服务和搜索服务分别计费；未配置搜索仍可基于本地资料及公开链接研究。
4. 导入文字、公开网页或带文本层的 PDF，然后在研究输入框选择参考资料并提出问题。
5. 在研究详情查看执行进度、证据、未知事项和下一步建议。可以停止任务、恢复中断任务、继续追问或导出 Markdown。

也支持环境变量 `LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`、`TAVILY_API_KEY` 作为配置后备；网页保存的设置优先。不会自动读取 `.env` 文件。

模型地址应填写到 `/v1` 或服务商根路径，**不包含 `/chat/completions`**；程序自动添加这个路径。非兼容协议（例如原生 Anthropic Messages）尚需增加适配器。

## 平台连接：小红书与 LinkedIn

打开 `http://127.0.0.1:8765/#social`，每个平台单独配置：

1. 点击「打开登录窗口」，在弹出的独立浏览器内手动登录或扫码。无需提供密码、Cookie 或日常浏览器配置路径。
2. 登录成功后回到应用，点击「检查登录状态」。检测到会话不等于保证任何页面都能读取，仍需下一步实际验证。
3. 勾选「允许助手自动使用这个平台」，保存采集配置。
4. 用「试搜关键词」验证站内搜索，再用一个具体笔记或 `/in/` 职业主页链接验证正文。结果自动进入资料库。
5. 研究时主 Agent 可调用 `search_social`；原有 `read_url` 自动把对应链接交给浏览器适配器。

默认每平台请求间隔至少 20 秒、每天最多 30 次页面导航（按 UTC 日期）。首次只读取最多 8 条搜索结果；不会自动翻页、无限滚动、展开全部内容或下载整份人员名单。小红书可收集笔记文字与当时显示的最多 10 条评论；LinkedIn 读取职业简介、工作、教育、技能等可见栏目，不读取消息、联系人或联系方式。

浏览器采集属于独立的、由用户显式连接的访问通道，不通过通用 HTTP 采集器，也不声称网站允许此类自动化。LinkedIn 明确限制抓取和自动化访问，账号可能被限制；请结合平台规则决定是否使用。普通个人登录 API 不提供任意人物检索能力。遇到登录、验证码、401/403/429 或连接异常，会保存暂停状态，后续采集不会自动继续，需要手动处理并重新检查。

登录态保存在 `data/browser-sessions/xiaohongshu/` 和 `data/browser-sessions/linkedin/`，目录权限为 `0700`，不包含在 JSON 导出中。「关闭连接」停止采集并保留登录态；「清除登录态」关闭独立浏览器并删除该目录。已收集的研究证据需在资料库另行删除。首次登录并检查成功后，重启服务会在下次采集时按需加载登录态，不必重复扫码。验证码、登录过期及连接错误状态仍保持暂停，需手动处理。

浏览器必须安装在运行服务的本机，应用需从桌面会话启动。自动寻找 Edge、Chrome、Chromium，也可以用 `APPLICATION_HELPER_BROWSER` 指定可执行文件；找不到时使用 Playwright 安装的 Chromium（`.venv/bin/python -m playwright install chromium`）。不连接日常浏览器、不使用 stealth、代理池、验证码破解或内部接口签名。

**验证范围：** 两个适配器的浏览器生命周期和 DOM 提取有测试夹具覆盖；你的真实账号、实时页面结构及搜索权限需完成登录后实测。这个通道不是官方 API，不能承诺平台持续可用。

## 数据与访问

- 默认资料路径：`data/`。可用 `APPLICATION_HELPER_DATA` 指定独立目录。
- 档案、记忆、证据、研究上下文与任务状态保存在 `data/application.db`；模型及搜索凭据保存在权限为 `0600` 的 `data/settings.json`。密钥文件为本机明文文件，不是加密保险库。
- 密钥不回显到 UI，不注入模型上下文，且不包含在数据导出中。`data/` 已加入 `.gitignore`。
- 模型会接收问题、相关工具结果，以及你允许分享的档案/已确认记忆；关闭档案分享后仍会发送你选择的资料及追问所需的上次报告。称呼不注入档案上下文。
- 历史任务保存当时上下文用于恢复。删除记忆不删除已存在的历史快照；需要时同时删除相关研究。删除资料库条目后，历史报告仍保留来源标题/链接，历史任务上下文也可能包含当时读取的片段；如需清理请同时删除对应研究。删除研究不会自动删除资料库证据。
- 网页采集校验公网 DNS 地址并固定到已验证 IP 建立连接，重定向重新检查，拒绝内网与保留地址；HTTPS 仍校验证书。
- 执行 robots.txt 检查；规则无法确认时停止；默认每站请求间隔至少 2 秒。超过当前适配器间隔能力的站点暂停访问。正文缓存 6 小时，历史资料由用户管理。
- Web 页面作为数据处理；没有开放 shell 或任意代码执行工具。写入 API 要求同源应用标识，配合 Host 检查和内容安全策略。当前版本不应直接对公网开放。

## 简历 PDF 导入

在「个人档案」点击「导入简历 PDF」。支持中英文带文本层 PDF，最多 5 MB、20 页和 30000 字符；扫描件暂不支持 OCR。先在本机提取并预览文字，可删除联系方式或修正排版，再点击「发送给模型并解析」，使用设置中已连接的模型整理教育、成绩、科研和工作等字段。此操作会发送预览框中的文字，不附带已有档案；研究中的档案分享开关不控制这次明确发起的简历解析。

逐项检查建议内容和对应原文后，选择需要填入的字段。已有内容默认不选中，选中则替换；最后点击「保存档案」持久保存，并沿用档案版本记录。解析不推算 GPA，不根据已有学位推断申请学位。原文引用校验不能保证模型总结完全准确，仍需核对。原始 PDF 和解析草稿不写入资料库或数据库，关闭窗口后需重新导入；发送给模型的文字按该服务商的数据规则处理。

登录态复用：独立浏览器目录之外，同目录 `session.json` 以 0600 权限保存平台 Cookie（包含会话 Cookie）。仅补充浏览器缺失且未过期的 Cookie，不延长有效期。第一次登录后点击检查状态或成功采集即可保存；关闭连接保留、清除登录态一并删除。登录态是本机敏感明文文件，不进入 Git、模型或 JSON 导出。平台可随时使会话失效，不能保证永久免登录。
